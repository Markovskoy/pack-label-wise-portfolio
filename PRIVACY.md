# Privacy Notice

This repository is a public engineering portfolio artifact.

## What It Contains

- Sanitized architecture notes
- Public-safe CI/CD examples
- Infrastructure skeletons
- Mock or redacted visuals

## What It Does Not Contain

- Real customer data
- Production database dumps
- Authentication secrets
- Private operational credentials
- Full proprietary application source code

## Publishing Rule

Before making the repository public, verify that any newly added screenshots, configs, or examples remain sanitized and do not reveal internal identifiers or customer information.
