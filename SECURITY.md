# Security Policy

## Scope

This public repository is a sanitized portfolio case study. It does not contain production secrets or the private application source code.

## Reporting A Concern

If you notice:

- accidentally published sensitive identifiers
- residual secrets or credentials
- documentation that exposes unsafe operational detail

please report it privately to the repository owner and do not open a public issue with sensitive content.

## Security Boundaries

- Examples use placeholders instead of real infrastructure identifiers.
- Production usernames, IPs, bucket names, distribution IDs, and zone IDs are intentionally excluded.
- Real customer data, dumps, and application secrets must never be committed.

## Disclosure Expectations

- Do not publish exploit steps against any live environment.
- Share only the minimum evidence needed to validate the issue.
- Prefer redacted screenshots and logs.
